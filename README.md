# Habitat Mapping (Hyperspectral)
Python based habitat mapping scripts for repeated creation of benthic cover maps, using hyperspectral satellite imagery. Scripts require georeferenced benthic photoquadrat data classified in ReefCloud, satellite hyperspectral imagery, and bathymetry. The processing scripts are initially setup for mapping across: the Eastern Banks in Moreton Bay, Queensland, Australia (seagrass); Heron Reef, Queensland (coral), both in Queensland, Australia. These scripts are divided into:

Field data pre-processing (R script).
Image pre-processing (GEE).
Calibration/validation assignment (GEE).
Habitat map classification (GEE).
